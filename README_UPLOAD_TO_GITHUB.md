# Upload This Portfolio to GitHub Pages

## What to Upload

This folder contains the **finished website**. It is already built. You do **not** need Node.js, a terminal, GitHub Actions, or any build command.

> Do not upload this ZIP file directly to GitHub. GitHub will store it as a download instead of opening the website. Unzip it first, then upload the files inside this folder.

## Five Simple Steps

1. In GitHub, open `https://github.com/kuriaian951-ui/kuriaian951-ui.github.io`.
2. Create a backup first: select **Code → Download ZIP**. Then delete the old website files in the repository, but do not delete the repository itself.
3. Select **Add file → Upload files**. Upload **everything inside this folder**, including `index.html`, `assets`, `favicon.svg`, `robots.txt`, and `sitemap.xml`. Do not upload the enclosing `IAN_KURIA_GITHUB_PAGES_DIRECT_UPLOAD` folder itself.
4. Commit the changes to the `main` branch with the message `Publish redesigned portfolio`.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, choose `/(root)`, then press **Save**.

GitHub will publish the site at `https://kuriaian951-ui.github.io/`. Wait a few minutes, then open that address in a private/incognito browser window to avoid a cached copy of the old site.

## Final Check

After publishing, check the navigation, the Kush Media Kit link, the WhatsApp button, and the project form. Submit one non-sensitive test message to confirm that the Web3Forms notification arrives at the configured inbox.
